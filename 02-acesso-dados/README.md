# 02 – Acesso a Dados

## Objetivo

Capacitar os participantes a manipular dados no Protheus utilizando workareas, aliases, ordens e funções como `DbSelectArea`, `DbSeek`, `DbSkip` e `DbAppend`, garantindo consultas eficientes e aderentes às boas práticas de performance.

## Estrutura do diretório

- **fonte‑base/**: scripts e exemplos iniciais utilizados nos exercícios de acesso a dados.
- **fonte‑resolvido/**: versões completas e otimizadas dos códigos, servindo como referência.

## Checklist de validação

- [ ] Criar e selecionar workareas com `DbSelectArea` e aliases apropriados.
- [ ] Realizar consultas utilizando `DbSeek` e `DbSkip` considerando ordens (índices).
- [ ] Implementar inserção, alteração e exclusão de registros de forma segura.
- [ ] Avaliar o desempenho das consultas e propor melhorias (uso de índices, filtros adequados).
