# 01 – Fundamentos

## Objetivo

Introduzir os participantes aos fundamentos do Protheus e da linguagem ADVPL, abordando a arquitetura (AppServer, DBAccess, SmartClient), a estrutura de ambientes (SIGACFG, SIGAADV, etc.), o conceito de RPO e dicionário de dados, bem como as tabelas padrão que servem de base para os módulos do sistema.

## Estrutura do diretório

- **fonte‑base/**: códigos e scripts de apoio utilizados nas demonstrações desta seção, servindo como ponto de partida para os exercícios práticos.
- **fonte‑resolvido/**: soluções completas ou exemplos finais para comparação após a conclusão dos exercícios.

## Checklist de validação

- [ ] Configurar e acessar um ambiente Protheus (SIGACFG/SIGAADV) via SmartClient.
- [ ] Identificar as principais tabelas padrão (por exemplo, SC5, SC6, SA1, SB1) e suas funções.
- [ ] Explicar a importância do RPO e do dicionário de dados (tabelas SX3, SX2, etc.).
- [ ] Navegar entre ambientes e entender os papéis do AppServer, DBAccess e SmartClient.
