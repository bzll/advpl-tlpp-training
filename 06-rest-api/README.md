# 06 – REST API

## Objetivo

Capacitar os participantes a criar e consumir APIs REST no Protheus, utilizando TLPP/ADVPL, desenvolvendo endpoints para integração com sistemas externos, aplicando autenticação, tratamento de JSON e boas práticas de segurança.

## Estrutura do diretório

- **fonte‑base/**: esboços de serviços REST e exemplos de requisições.
- **fonte‑resolvido/**: implementações completas de APIs e clientes de consumo.

## Checklist de validação

- [ ] Criar um endpoint REST no Protheus utilizando TLPP.
- [ ] Consumir uma API externa e tratar o retorno JSON.
- [ ] Implementar autenticação (token, basic ou OAuth) quando necessário.
- [ ] Validar a integridade e segurança das requisições e respostas.
