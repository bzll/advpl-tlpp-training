# Laboratórios

Este diretório reúne os materiais de apoio para os laboratórios práticos do treinamento.

## Estrutura

- **`fonte-base/`**: contém os códigos ou scripts iniciais que os participantes devem utilizar como ponto de partida para os exercícios. Estes arquivos servem como esqueleto das rotinas a serem implementadas durante as aulas práticas.

- **`fonte-resolvido/`**: guarda as soluções sugeridas (resolvidas) para cada um dos laboratórios. Após concluir os exercícios, consulte este diretório para comparar sua implementação e entender a abordagem proposta.

## Instruções

1. Para cada exercício, copie o conteúdo de `fonte-base/` para o diretório apropriado (ou para sua área de trabalho) antes de iniciar o desenvolvimento.
2. Desenvolva e teste sua solução seguindo as orientações do instrutor e o conteúdo dos módulos correspondentes.
3. Depois de finalizar, revise o código presente em `fonte-resolvido/` para verificar diferenças e identificar melhorias.
