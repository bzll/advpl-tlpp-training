# 03 – MVC

## Objetivo

Introduzir o padrão MVC (Model‑View‑Controller) no Protheus, demonstrando como estruturar rotinas em camadas, separar regras de negócio da interface e construir aplicações modulares usando classes e frameworks nativos como `FWForm`, `FWMBrowse`, `ModelDef`, `ViewDef` e `MenuDef`.

## Estrutura do diretório

- **fonte‑base/**: modelos de rotinas MVC que servem como ponto de partida.
- **fonte‑resolvido/**: implementações completas de rotinas MVC para referência.

## Checklist de validação

- [ ] Criar uma rotina simples utilizando `ModelDef`, `ViewDef` e `MenuDef`.
- [ ] Implementar navegação de dados usando `FWMBrowse` e `FWForm`.
- [ ] Separar lógica de negócio da interface em métodos adequados.
- [ ] Testar a rotina MVC no ambiente Protheus, validando seus componentes.
